# strwTranslate
> translate the page in one click, just how it should be
> <img src="icon512.png" align="right" style="width:150px; height:auto;"/>

this extension translates an entire page in batches using google's API. it has configurable settings and supports multiple languages of choice, meaning that most pages will translate to your language of choice easily, fast and efficient.

## installation
the installation is relatively simple. it works fully standalone.
1. download this portion of the repository
2. unzip the folder you were provided somewhere safe
3. go to the extensions of your browser and turn on developer mode
4. press "Load Unpacked" and select the folder with all the files

boom! your extension should be working!

> [!WARNING]
> this uses google's API for translation, meaning google may track what you're translating.
